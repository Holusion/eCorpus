# Navigating a 3D Scene

In an eCorpus scene, the camera turns around a point: the **pivot**. You can rotate the view, zoom, move it around and pick another pivot, with a mouse, a finger or the keyboard. These controls are the same wherever a scene is shown, on eCorpus or on a website that embeds it.

**Three types of interactions are supported:**

- [Mouse](#with-a-mouse)
- [Touch screen](#on-a-touch-screen)
- [Keyboard](#with-the-keyboard)

## With a mouse

{% include demo-video.html src="/assets/video/doc/navigation_mouse_en.mp4" poster="/assets/img/doc/navigation_mouse_en.webp" title="With a mouse: rotate, zoom, pan and set the pivot" %}

| To… | With a mouse |
|---|---|
| Rotate around the model | Left-click and drag |
| Zoom | Mouse wheel (or middle-click and drag, or Alt + left-click and drag) |
| Pan the view | Right-click and drag (or Ctrl + left-click and drag) |
| Set the pivot | Double-click on the model |
| Tilt the view | Alt + right-click and drag |

## On a touch screen

{% include demo-video.html src="/assets/video/doc/navigation_touch_en.mp4" poster="/assets/img/doc/navigation_touch_en.webp" title="With a finger: rotate, zoom, pan and set the pivot" %}

| To… | With a finger |
|---|---|
| Rotate around the model | Drag one finger |
| Zoom | Pinch or spread two fingers |
| Pan the view | Drag two fingers |
| Set the pivot | Double-tap the model |

## With the keyboard

{% include demo-video.html src="/assets/video/doc/navigation_keyboard_en.mp4" poster="/assets/img/doc/navigation_keyboard_en.webp" title="With the keyboard: rotate, zoom and pan" %}

First click in the scene (or reach it with the Tab key) so that the keyboard acts on it.

| To… | With the keyboard |
|---|---|
| Rotate around the model | Arrow keys |
| Zoom | Ctrl + Up / Down arrow |
| Pan the view | Shift + arrow keys |

The pivot cannot be changed with the keyboard.

*On a Mac, Ctrl + Up / Down opens Mission Control or App Exposé: zoom with the mouse or trackpad instead, or turn these shortcuts off in the Mac's Keyboard settings.*

## The pivot point

At first, the pivot sits at the centre of the model. To look at a detail, double-click it (or double-tap it): the camera turns to bring it to the centre of the view, then rotation and zoom happen around this new point.

To go back to the initial view, click the <i class="fa fa-undo" aria-hidden="true"></i> *Reset* button at the bottom right of the scene.
