{%comment %} iframe embed for eCorpus scenes Usage : include voyager.html url="https://ecorpus.example.com/ui/scenes/item-id/view" title="..." `url` is the canonical scene viewer URL (the one you copy from the browser when looking at the scene). The iframe embeds it as-is. `title` is required (the build fails without it). Used for the iframe title, the poster alt text, the figcaption and the JSON-LD name. Copy the scene's own title (metas[].collection.titles in the scene's https:///scenes//scene.svx.json document) when it carries a meaningful value, otherwise write your own. Unless the URL (or `params`) already sets a `lang=` value, the current page language is appended automatically (e.g. `?lang=FR`). A poster image (the scene-image-* renders published by the eCorpus server) is always rendered so search engines and no-JS browsers see an indexable image instead of an empty rectangle. By default it is shown with a "play" button and the heavy iframe viewer is only loaded once the user clicks it, so no superfluous data is fetched for uninterested visitors. The iframe is part of the markup, inert (data-src, hidden by the .ecorpus-facade styles). The script promotes data-src to src on click (or immediately with autoplay) and reveals the viewer only once it has actually loaded, so the poster survives when the cross-origin viewer never loads (search engines, server down). Optional : autoplay=true Replace the poster with the iframe viewer as soon as the page loads instead of waiting for a click. Defaults to false. placeholder="/assets/img/path/to/poster.webp" Custom poster image, used in place of the server's scene-image-* renders. params="..." Extra query string appended to the scene URL.
