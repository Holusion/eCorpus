# Naviguer dans une scène 3D

Dans une scène eCorpus, la caméra tourne autour d'un point : le **pivot**. Vous pouvez faire tourner la vue, zoomer, la déplacer et choisir un autre pivot, à la souris, au doigt ou au clavier. Ces commandes sont les mêmes partout où une scène est affichée, sur eCorpus comme sur un site qui l'intègre.

**Trois méthodes d'interaction sont supportées:**

- [Souris](#à-la-souris)
- [Écran tactile](#sur-écran-tactile)
- [Clavier](#au-clavier)

## À la souris

{% include demo-video.html src="/assets/video/doc/navigation_mouse_fr.mp4" poster="/assets/img/doc/navigation_mouse_fr.webp" title="À la souris : tourner, zoomer, déplacer la vue et changer le pivot" %}

| Pour… | À la souris |
|---|---|
| Tourner autour du modèle | Clic gauche et glisser |
| Zoomer | Molette (ou clic molette et glisser, ou Alt + clic gauche et glisser) |
| Déplacer la vue | Clic droit et glisser (ou Ctrl + clic gauche et glisser) |
| Changer le pivot | Double-clic sur le modèle |
| Incliner la vue | Alt + clic droit et glisser |

## Sur écran tactile

{% include demo-video.html src="/assets/video/doc/navigation_touch_fr.mp4" poster="/assets/img/doc/navigation_touch_fr.webp" title="Au doigt : tourner, zoomer, déplacer la vue et changer le pivot" %}

| Pour… | Au doigt |
|---|---|
| Tourner autour du modèle | Glisser un doigt |
| Zoomer | Pincer ou écarter deux doigts |
| Déplacer la vue | Glisser deux doigts |
| Changer le pivot | Toucher deux fois le modèle |

## Au clavier

{% include demo-video.html src="/assets/video/doc/navigation_keyboard_fr.mp4" poster="/assets/img/doc/navigation_keyboard_fr.webp" title="Au clavier : tourner, zoomer et déplacer la vue" %}

Cliquez d'abord dans la scène (ou atteignez-la avec la touche Tab) pour que le clavier agisse sur elle.

| Pour… | Au clavier |
|---|---|
| Tourner autour du modèle | Flèches |
| Zoomer | Ctrl + flèche haut / bas |
| Déplacer la vue | Maj + flèches |

Le pivot ne peut pas être changé au clavier.

*Sur Mac, Ctrl + flèche haut / bas ouvre Mission Control ou App Exposé : pour zoomer, utilisez plutôt la souris ou le pavé tactile, ou désactivez ces raccourcis dans les réglages Clavier du Mac.*

## Le point de pivot

Au départ, le pivot est placé au centre du modèle. Pour examiner un détail, double-cliquez dessus (ou touchez-le deux fois) : la caméra se tourne pour le placer au centre de la vue, puis les rotations et le zoom se font autour de ce nouveau point.

Pour revenir à la vue de départ, cliquez sur le bouton <i class="fa fa-undo" aria-hidden="true"></i> en bas à droite de la scène.
